The Go Report Card badge shows the status of quality checks for all eligible registered Go modules.
The coverage badge shows cumulative statement coverage on the `main` branch for all registered Go
modules that publish coverage. Codecov requires each module flag to maintain at least 75% coverage
after excluding generated code and test support.

This project is an exercise in migrating the
original [Micronaut Microservices POC](https://github.com/asc-lab/micronaut-microservices-poc) from
Java/Micronaut to Go.

See [System Overview and Migration Analysis](/docs/system-overview-and-migration-analysis.md)

Read ["Insurance Hub: The Way to Go"](https://www.kiroule.com/series/insurance-hub-the-way-to-go/) 
series to get more insight into how the migration proceeds.
