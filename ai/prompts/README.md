# Reusable Prompts

Reusable agent prompts live here. Load the prompt that matches the requested task:

- [Session bootstrap](session-bootstrap.md): repository startup and ticket context.
- [Pull request description drafting](pr-description-drafting.md): prepare a local PR description
  from ticket requirements, implementation evidence, and the shared PR template.
- [Pull request review drafting](pr-review-drafting.md): prepare a vendor-neutral, evidence-based
  local review from ticket requirements, repository rules, and the complete proposed change.
